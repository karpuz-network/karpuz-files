## 🏗️ Yapı

```
karpuz-files/
├── pack.toml              # Packwiz ana konfigürasyonu
├── index.toml             # Dosya hash indexi (otomatik)
├── mods/                  # Mod metadata dosyaları (.pw.toml)
│   ├── apotheosis.pw.toml
│   ├── alexscaves.pw.toml
│   └── ...
├── config/                # Mod konfigürasyonları
│   └── fancymenu/         # FancyMenu özelleştirmeleri
├── resourcepacks/         # Özel resource pack'ler
│   └── karpuz-resouce-pack-0.1/
├── options.txt            # Minecraft istemci ayarları
├── servers.dat            # Sunucu listesi
└── .github/workflows/     # CI/CD otomasyonu
    ├── refresh-hashes.yml # Otomatik hash yenileme
    └── validate.yml       # PR doğrulama
```

## 🚀 Kurulum

### Oyuncu (Launcher ile)
Karpuz Launcher otomatik olarak bu repoyu kullanarak modpack'i indirir ve doğrular.

### Geliştirici
```bash
# Repoyu klonla
git clone https://github.com/karpuz-network/karpuz-files.git

# Packwiz kur
go install github.com/packwiz/packwiz@latest

# Mod ekle
packwiz curseforge add <mod-adı>
# veya
packwiz modrinth add <mod-adı>

# Index'i yenile
packwiz refresh
```

## 🔧 Geliştirme

### Mod Ekleme
```bash
packwiz curseforge add <mod-adı>
```

### Mod Güncelleme
```bash
packwiz update --all
# veya tek mod:
packwiz update <mod-adı>
```

### Mod Kaldırma
```bash
packwiz remove <mod-adı>
```

### Hash Yenileme
Config dosyalarında değişiklik yaptıktan sonra:
```bash
packwiz refresh
```

## 📝 Katkıda Bulunma

1. Bu repoyu fork edin
2. Feature branch oluşturun (`git checkout -b feat/yeni-mod`)
3. Değişikliklerinizi commit edin (`git commit -m "mod: yeni mod eklendi"`)
4. Branch'inizi push edin (`git push origin feat/yeni-mod`)
5. Pull Request açın

### Commit Formatı
```
mod:   Mod ekleme/güncelleme/kaldırma
config: Konfigürasyon değişiklikleri
fix:   Hata düzeltmeleri
chore: Bakım işlemleri
```
